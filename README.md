# last.fm Scrobble Cluster
A tool that **analyses** your **last.fm history** and **cluster duplicate tracks**, *that is: **re-scrobbling** tracks that were scrobbled in an URL that has a lower playcount than an already existent playcount in the same track but at another URL*, so that the **highest** playcount URL **receive the scrobbles** that were **wrongly** scrobbled in a **different URL**.

To sum up: [lastfm-scrobbles-cluster](https://github.com/tarcizoneto/lastfm-scrobbles-cluster) can be used when there are two clusters of scrobbles of the exactly same track, when it is meant to be there only one, this script get those together.
